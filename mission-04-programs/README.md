## 4. My Understanding

- **Python Program:** A set of instructions written in Python that the computer executes.
- **Compiler:** Translates source code into another form before execution.
- **Interpreter:** Reads and executes instructions during runtime.
- **Main Difference:** A compiler translates before execution, while an interpreter translates and executes instructions during runtime.
