## 4. My understanding

I learned that computer networks allow devices to communicate and exchange information.

LAN, MAN and WAN describe networks based on the geographical area they cover. DNS translates domain names into IP addresses, while routers forward data between networks.

Protocols provide rules for communication. Packet switching divides data into smaller packets, and the client-server model describes how a client requests information from a server.

I also understood that opening a website involves several steps, including a DNS lookup, establishing communication with a server, sending a request and receiving a response that the browser displays.

## 5. Difficulties faced

- Understanding the different networking concepts and how they relate to one another.
- Interpreting the output produced by `ping` and `nslookup`.
- Understanding the sequence of events involved in opening a website.

## 6. How I resolved them

I reviewed the purpose of each networking concept and used Terminal commands to observe actual network information.

I compared the connectivity test and DNS lookup results to understand what each command checks and how DNS helps locate a server.

I also organised the website-loading process into individual steps to understand how the browser, client, server, router and protocols work together.
