
# Mission 1 - Know Your Computer

## Task 1.1 - Trace One Activity Using IPOS

**Activity chosen:** Typing and saving a document.

IPOS stands for Input, Processing, Output and Storage. These are the four main stages involved when a computer handles information.

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text into a document using the keyboard. | Keyboard |
| Processing | The CPU processes the text entered and prepares it to be displayed. | CPU and RAM |
| Output | The typed text appears on the computer screen. | Monitor |
| Storage | When I save the document, it is stored so I can access it later. | SSD |

### How the activity works:
First, I enter text using the keyboard. The computer processes the information using the CPU and memory. The result is displayed on the monitor. Finally, when I save the document, it is stored on the SSD for future use.
