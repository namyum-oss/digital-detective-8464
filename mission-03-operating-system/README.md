## 3. Commands / Tools Used

| Command | Purpose |
|---|---|
| `uname -a` | Displays operating-system and kernel information. |
| `whoami` | Displays the current username. |
| `df -h` | Displays available and used storage. |
| `top -l 1` | Shows a snapshot of system activity. |
| `ps aux` | Displays running processes and their details. |
| `pwd` | Displays the current directory. |
| `cd` | Changes the current directory. |
| `ls -l` | Displays files with detailed information, including permissions. |

## 4. My Understanding

- **Operating System:** Manages the computer's hardware and provides services to applications.
- **Process:** A program that is currently running. Each process has a unique Process ID (PID).
- **Storage:** `df -h` helps check total, used and available storage.
- **Absolute Path:** Gives the complete location of a file or folder.
- **Relative Path:** Gives a location in relation to the current directory.
- **File Permissions:** `r` means read, `w` means write and `x` means execute.
- **OS Responsibilities:** The OS manages processes, memory, devices, files, user interaction, security and permissions.
