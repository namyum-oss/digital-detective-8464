# Mission 2 – Become Comfortable with the Terminal

## 1. Task / Objective

The objective of this mission was to learn how to use the Terminal to navigate directories, manage files, understand command options and pipes, and learn about package managers.

## 2. Work Completed

- **Task 2.1:** Practised basic Terminal commands such as `pwd`, `ls`, `ls -l`, `cd`, `mkdir`, `touch`, `cp`, `mv` and `cat`.
- **Task 2.2:** Created a `terminal-practice` folder, added two lines to a text file, displayed its contents, created a backup copy and renamed it.
- **Task 2.3:** Practised using flags with the `ls` command and understood how pipes work using `ls -lah | head`.
- **Task 2.4:** Explored Homebrew, a package manager for macOS, by checking its version and installed packages.

## 3. Commands / Tools Used

| Command | Purpose |
|---|---|
| `pwd` | Displays the current directory path |
| `ls` | Lists files and folders |
| `ls -l` | Displays a detailed listing |
| `ls -a` | Includes hidden files |
| `ls -lh` | Displays human-readable file sizes |
| `ls -lah` | Combines detailed listing, hidden files and readable sizes |
| `cd` | Changes the current directory |
| `mkdir` | Creates a directory |
| `touch` | Creates an empty file |
| `echo` | Writes text into a file |
| `>` | Replaces file contents |
| `>>` | Appends text to a file |
| `cat` | Displays file contents |
| `cp` | Copies a file |
| `mv` | Moves or renames a file |
| `head` | Displays the first few lines of input |
| `brew --version` | Checks the Homebrew version |
| `brew list` | Lists Homebrew-managed packages |

## 4. My Understanding

I learned how to navigate directories and manage files using Terminal commands. I understood the difference between replacing and appending file contents, as well as copying and moving files.

I also learned that flags modify how commands behave and that pipes allow the output of one command to be passed as input to another command. I understood that package managers help manage software and its dependencies.

## 5. Difficulties Faced

Initially, I needed to understand how flags and pipes work together.

## 6. How I Resolved Them

I practised the commands individually and checked their outputs. This helped me understand how each command and option changes the result.
