# Mission 5 — Numbers and Data

## 1. Task / objective

To understand how computers represent numbers and text by converting decimal, binary and hexadecimal values, verifying conversions using Python, building a number converter and learning about ASCII encoding.

- Explained why character encoding standards are needed.

## 3. Commands / tools used

**Terminal commands:**
- `python3` — Used to run the Python program.

**Python functions:**
- `int()` — Converts the input into an integer.
- `bin()` — Converts an integer into binary.
- `hex()` — Converts an integer into hexadecimal.
- `print()` — Displays the results.

## 4. My understanding

Computers represent information using binary digits (0 and 1). Decimal, binary and hexadecimal are different number systems used to represent values.

Python provides built-in functions such as `bin()` and `hex()` to convert integers into different number systems. ASCII assigns numerical codes to basic characters, while Unicode supports a much wider range of characters.

## 6. How I resolved them

Practised the conversion methods step by step, used place values and repeated division, and verified the results using Python.
