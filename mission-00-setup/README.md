
# Mission 00 - Create Your GitHub Workspace

## 1. Task / Objective

The objective of this mission was to create a GitHub repository with the correct name and prepare a folder structure for all the missions in the Digital Detective assignment.

**Repository name:** digital-detective-8464

The repository was created as a public GitHub repository.

## 2. Work Completed

- Created a local project folder named `digital-detective-8464`.
- Created a GitHub repository with the same name.
- Created folders for all nine missions (Mission 00 to Mission 08).
- Created a separate README.md file inside each mission folder.
- Created the root README.md for the overall assignment.
- Initialised Git and connected the local project to GitHub.
- Pushed the project files to GitHub.

## 3. Commands / Tools Used

| Command / Tool | Purpose |

## 4. My Understanding

A repository is a place where project files and their changes are stored and managed using Git. Git helps track changes and allows us to save different versions of our work through commits.

The folder structure is organised by missions so that the work for each mission stays separate and easy to find. Each mission has its own README file where the activities, commands, learning and difficulties can be documented.

The root README provides an overview of the entire assignment and links to the individual missions.

## 5. Difficulties Faced

Initially, I was unfamiliar with Markdown formatting. I did not know how to properly create headings, subheadings, bold text, bullet points and tables.

I also faced some difficulties while connecting my local repository to GitHub and pushing the files.

## 6. How I Resolved Them

I learned the basic Markdown syntax and practised using it while creating and formatting the README files.

For the GitHub connection issue, I checked the remote repository URL, verified the repository name and corrected the connection. I also learned that changes on GitHub and local changes need to be synchronised before pushing.
