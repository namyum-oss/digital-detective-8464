## 3. Commands / tools used

| Command / tool | Purpose |
|---|---|
| `git status` | Checks the current state of the working directory and staging area. |
| `git add` | Stages selected changes for a commit. |
| `git commit` | Records staged changes in Git history. |
| `git log` | Displays previous commits. |
| `git branch` | Creates or lists branches. |
| `git switch` | Switches between branches. |
| `git push` | Publishes local commits to the remote repository. |
| `git pull` | Retrieves and integrates remote changes. |
| GitHub | Hosts the repository and supports collaboration through Pull Requests. |

## 4. My understanding

Git is a version control system that tracks changes made to files. GitHub is an online platform that hosts Git repositories and provides collaboration features.

Staging means selecting changes that will be included in the next commit. Committing records those staged changes in the repository history.

A branch is a separate line of development that allows changes to be made without directly modifying the main branch.

A Pull Request allows changes from one branch to be reviewed before they are merged into another branch. This makes collaboration easier and helps identify problems before changes become part of the main project.
